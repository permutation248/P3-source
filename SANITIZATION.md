# Sanitized source release

This archive intentionally contains source code only. It excludes benchmark
and task datasets, experiment results and traces, databases, workspaces,
backups, build products, dependency caches, virtual environments, editor and
agent-local configuration, credentials, and Git history.

Personal names, email addresses, machine-specific paths, repository branding,
and logos were removed or replaced with neutral placeholders. The private
`quickcheck` dependency URL is represented by an anonymous placeholder and
must be replaced with the release location supplied with the artifact.
